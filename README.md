# BirEksik

İzmir Ekonomi Üniversitesi öğrencileri için spor eşleştirme uygulaması —
padel partneri/rakibi bul, halı saha kadrosunu tamamla.

- **Canlı:** https://bireksik.com
- **Teknoloji:** Vite + React (SPA), Supabase (Auth + Postgres + RLS), Cloudflare Workers
- **Otomatik yayın:** `main` dalına her push → Cloudflare derleyip yayınlar

## Geliştirme
```
npm install
npm run dev
```

## Veritabanı
`supabase/` içindeki SQL dosyaları sırayla Supabase SQL Editor'de çalıştırılır.
